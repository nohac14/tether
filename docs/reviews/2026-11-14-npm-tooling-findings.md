# New glob-tooling advisory — 2026-11-14

**Status:** Owner-approved scoped remediation implemented and verified.

The refreshed pinned-runtime `pnpm audit` fails with one moderate finding,
[GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249),
published after the last recorded clean npm audit. It affects minimatch
>=7.0.0 and <11.0.1, including the locked 10.2.6. Pattern preprocessing can
amplify attacker-controlled glob patterns and exhaust resources. These are
development/lint consumers, not a LAN application endpoint; do not claim a
demonstrated remote-input exploit or suppress the failed dependency gate.
